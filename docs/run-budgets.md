# 运行预算与收尾

每次 Agent 运行分别计算常规模型请求和实际工具执行次数。一个响应里有多个工具调用时逐个计数，未执行的调用会收到阻止原因，保持工具调用与结果配对完整。

## 默认配置

在「设置 → 模型 API」调整。除 `api.maxRounds` 外，以下配置位于根级 `runLimits`。

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| `api.maxRounds` | 12 | 常规模型 HTTP 请求尝试次数，网络重试也计数 |
| `maxToolCalls` | 12 | 常规工具实际执行总次数，包括发送、finish 和 MCP |
| `maxSearchCalls` | 3 | `web_search` 次数，0 禁用 |
| `maxPageReads` | 4 | `web_fetch` 次数，0 禁用 |
| `maxImagePages` | 4 | `get_webpage_images` 次数，0 禁用 |
| `maxInputTokens` | 120000 | 累计聊天模型已报告的输入 token，包括缓存输入 |
| `maxRunMs` | 180000 | 探索阶段运行时间，毫秒 |
| `noProgressLimit` | 3 | 连续无新结果次数 |
| `toolResultMaxChars` | 6000 | 单条工具文本结果字符上限 |

任一总预算或无进展条件触发就停止继续探索；不要求把其他预算也耗光。搜索、读网页、提取图片的子额度用完，只阻止该类调用，模型可以改用已有结果和其他工具。重复的规范化搜索词、相同网页地址在本次运行中不重复执行；换词却只得到相同链接也不算新进展。工具错误、空候选、重复请求会累积无进展计数，新的搜索来源、图片地址或正文会重置计数。

每次常规模型请求前，在上下文末尾追加剩余额度快照：常规模型、工具、各搜索类别、已报告输入、剩余时间和无进展计数；模型或工具只剩 2 次及以下时明确提醒尽快交付。快照标注为提交当前请求前的数值，包含本次请求，传输重试间不改写该快照。新快照只追加，不改动旧前缀。控制台会话详情和 JSON 均可查看。

计数在请求或工具之间检查，不中断正在进行的请求；输入阈值依赖上游已报告的 usage，不能作为硬账单上限。搜索子模型用量独立记录，不纳入聊天模型输入阈值，搜索请求次数仍受工具预算限制。单次搜索服务内部的检索次数由上游控制。收尾使用独立预留次数，可能使总时长和总输入超过常规阈值。

## 收尾行为

达到停止条件且本轮没有实际发言时，将本轮所有已保留工具结果（包括最后一次结果）交给模型，使用独立收尾预算：

- 最多 3 次模型请求、4 次工具执行，固定上限；每种工具最多尝试一次。
- 仅允许原权限和视觉设置已开放的 `import_image`、`inspect_image`、`get_message_images`、`send_image`、`send_message`。用于导入已有链接、确认图片与交付，不开放新搜索、读网页、生图或 MCP。
- 同一模型响应中，前面的调用刚耗尽常规预算时，后面的看图和发送可以立即使用这份预留额度；不会重置额度。导入→看图→发送可分三轮完成，视觉结果进入下一轮输入，日志不保存图片字节。
- 模型直接输出文字也可以完成交付，不要求继续调用工具。三轮仍未交付时，额外保留一次不带工具的纯文字请求，并投递已有结果或未完成说明。
- 不自动网络重试，不重跑整轮；工具执行和文字投递均走现有权限检查、限流和发送队列。已尝试发送但结果未知时不自动重复该发送操作；图片失败可补一条文字说明，文字失败则记录错误停止。

已经发送过消息时不补发。模型在预算内正常 `finish` 或自行沉默不强制收尾。暂停、停止、会话禁用、隐私权限变化仍可阻止收尾；模型空输出、请求失败或发送失败明确记录为错误，不承诺外部服务故障时一定收到回复，也不在发送结果不确定时自动重发。

会话保存 `budget`、`terminationReason`、`finalization` 和逐工具 `toolCounts`；用量阶段区分首次、续轮、收尾。实际成功模型响应计入 `usage.calls`，常规 HTTP 尝试数查看 `budget.modelAttempts`，收尾请求数查看 `finalization.modelAttempts`，预留工具次数查看 `budget.completion` / `finalization.toolCalls`；请求失败时尝试数与成功响应数可能不同。常规工具和预留工具分别计数，逐条工具日志标明预留/收尾执行。

## 减少重复输入

- `web_fetch` 提取最多 5000 字符正文，过滤脚本、样式和导航。
- OpenCodex 搜索摘要最多 1600 字符；子模型计量不送回聊天模型。
- 工具长文本截断，搜索或图片列表优先删除完整条目，避免把半截 URL 当作可用链接。会话工具日志保存模型实际收到的文本及原始长度。
- 模型原始响应保留在本地日志，但不会作为下一次请求的 assistant 字段再次发送。当前运行仍保留有效调用和结果，后续运行不携带此前工具输出。
- 图片提取拒绝不可解析的编码地址，并过滤常见 logo、头像、二维码；静态 HTML 无法提供的图片不猜地址。

## 搜索用量

`searchUsageCalls` 单列 OpenCodex / DeepSeek 搜索子模型的已报告用量、模型和服务名称。即使搜索结果缺少来源而被拒绝，只要拿到完成响应的 usage，也会记录。缺失用量标为未知，不解释成零消耗。旧日志只能恢复仍完整保留的统计，页面提示覆盖不完整。费用按模型单价估算，独立搜索服务费和订阅实际额度不在此统计内。

验证：`npm run test:budget`、`npm run test:search`、`npm run test:usage`、`npm run test:render`、`npm test`。测试使用隔离数据、模拟模型和发送器，不调用真实付费模型或 QQ。
