# QQ 身份、工具权限与直接命令

在「设置 → 权限与命令」填写管理员 QQ 和交互风格。管理员身份按 OneBot 入站消息的真实发送者 QQ 判断，在群聊和私聊中一致；QQ群主、群管理员、昵称、他人转述和记忆中的身份声明均不授予权限。管理员列表默认为空。

普通聊天保留原有人设，并仅对程序核验的管理员 QQ 应用交互风格。该身份不改变记忆可见范围，也不让包含管理员发言的整个群聊批次获得工具权限。

## 直接命令

- `/帮助`：查看本人可用的命令。
- `/权限`：查看本人的机器人权限角色。
- `/电脑状态`：内置管理员命令，无参数，直接返回本机基础运行指标。
- `/命令名 {"参数":"值"}`：调用本机控制台已注册的工具；无参数时可以只发命令名。
- `/确认 编号`、`/取消 编号`：处理一次具体操作的待确认任务。

首版命令由程序直接解析并执行映射工具，不经过 LLM，不产生模型费用。参数采用 JSON 对象，不猜测目标或自由文本参数；没有 shell 命令拼接。未来具体工具确定后，可以在命令入口增加各自的参数解析器。

只有消息开头为 `/` 的直接纯文本消息才参与解析。引用、合并转发、图片、带 @ 的消息、CQ 码和展开后的历史显示文本都不能触发命令。旧存档没有独立的 `commandText` 字段，因此不会被回溯当作授权。

命令一次只处理一条消息；同批其他未读消息保留并另行唤醒。命令不依赖聊天响应档位或模型配置，但仍受机器人暂停、并发上限、聊天白名单和用户屏蔽规则约束。

## 第一个管理员工具：电脑状态

在「设置 → 权限与命令」保存管理员 QQ 后，由该 QQ 在允许的群聊或私聊发送 `/电脑状态`。这是内置命令，无需修改命令注册 JSON；默认每 QQ、每会话每分钟最多调用 3 次，默认无需二次确认。

机器人在当前会话直接回复：

- 系统类型、版本与架构。
- CPU 短时平均使用率（约 500 毫秒采样）及逻辑核心数；不是瞬时峰值或长期负载。
- 全机已用/总内存与使用率。
- NVIDIA GPU 利用率、已用/总显存及显存占用比例，多块显卡逐张显示。利用率采用驱动提供的采样值，与 CPU 采样窗口不必相同。
- Windows 上程序数据所在分区、系统分区的可用/总空间（相同分区只列一次）；其他平台读取程序数据所在文件系统。不会扫描所有磁盘或文件。
- 系统开机时长、机器人进程运行时长和进程 RSS 内存。

不读取文件内容、进程列表、电脑名、用户名、IP 地址或凭据；不执行 shell，也不调用模型或发现 MCP 服务。GPU 使用 [NVIDIA nvidia-smi](https://docs.nvidia.com/deploy/nvidia-smi/) 的固定只读查询，通过 `execFile` 隐藏窗口调用；参数和程序路径不接受 QQ 输入。Windows 依次查找系统目录 `System32`、Program Files 下 `NVIDIA Corporation/NVSMI`，Linux 查找 `/usr/bin`、`/usr/local/bin`，不从当前目录或任意 PATH 搜索可执行文件。查询限制两秒、输出限制 64 KiB；只有程序不存在才尝试下一位置。未安装、驱动错误、超时或 AMD/Intel/不支持的平台显示 GPU 暂不可用，不影响 CPU 等其他指标；驱动返回 N/A 的字段单独显示不可用。暂不采集温度、风扇等指标。磁盘异常或两秒内未返回时，仅该项显示“暂不可用”。

工具 ID 为 `builtin:get_computer_status`，代码声明强制管理员角色，配置成 public 也不会让普通用户调用。可在工具规则 JSON 中设置 `{"builtin:get_computer_status":{"role":"disabled"}}` 禁用，或配置 `chats`、`maxCallsPerMinute`、`confirm`。内置命令名不可重新映射；也可以注册指向该工具的其他命令名。

采集前、采集后及 QQ 队列实际发出前都会检查权限；途中撤销管理员、屏蔽用户、修改规则或暂停机器人时，不发送状态结果。只读指标及权限审计保存在本地会话中，原始命令仍留档。

## 工具规则与注册示例

原生工具使用 `builtin:工具名`，MCP 使用 `mcp:服务ID:原始工具名`。MCP 的服务 ID 和原始工具名称可在 MCP 管理接口 `/api/mcp/servers` 的发现结果中查看，不使用发送给模型的哈希工具名。

下面的规则将现有的群成员查询改为管理员命令。它只是一个可用的接入示例，程序没有默认应用此配置，也没有注册重启、禁言、删除文件等工具。

工具规则：

```json
{
  "builtin:get_group_members": {
    "role": "admin",
    "chats": ["group:123456"],
    "maxCallsPerMinute": 3,
    "confirm": false,
    "argsSchema": {
      "type": "object",
      "properties": { "limit": { "type": "integer", "minimum": 1, "maximum": 20 } }
    }
  }
}
```

命令注册：

```json
{
  "查成员": {
    "tool": "builtin:get_group_members",
    "description": "查询当前群成员"
  }
}
```

替换示例群号后，在该群由管理员直接发送 `/查成员 {"query":"小明","limit":10}`。该工具结果保存在控制台会话的「权限与命令记录」，QQ 中只回复执行状态。电脑状态工具提供专用格式化回复；其他工具默认仍不将原始结果发布到 QQ。工具自身的主动发言（例如 send_message）仍按工具逻辑发送。

| 字段 | 含义 |
| --- | --- |
| `role` | `public` 普通聊天可用；`admin` 仅已注册的管理员命令可用；`disabled` 全部聊天禁用 |
| `chats` | 省略表示沿用工具已有聊天范围；列表限制到指定会话；空列表表示禁止所有会话 |
| `maxCallsPerMinute` | 同一工具按 QQ 跨群计数，同时按会话计数；普通批次中的各发送者均计入。受限工具默认每分钟 5 次 |
| `confirm` | 仅用于 admin 工具；需要本人确认本次固定参数 |
| `argsSchema` | 附加 JSON Schema，用于目标枚举、数值范围等约束，与工具自身参数要求叠加 |

所有命令另有每 QQ 每分钟 10 次、全局每分钟 100 次的入口限制。未单独配置的现有工具维持原有开放范围；新 MCP 工具仍须先在 MCP 管理页启用。新开发的原生敏感工具应声明 `requiredRole: 'admin'`，避免漏写配置后默认公开；此声明不能被 public 规则降级。

## 执行边界与记录

普通聊天的工具列表剔除受限工具，实际执行入口再检查当前规则。命令授权绑定发送者、会话、源消息、唯一工具、参数哈希与有效期，不能通过模型参数构造身份。授权只使用一次。

确认编号随机生成，绑定原 QQ、原会话和固定参数；普通的“可以”不算确认。编号最多有效两分钟，且原命令接收五分钟后失效。确认被并发重复提交也只消费一次。管理员撤销、屏蔽、聊天范围收紧、命令映射或规则变更，以及 MCP 配置或参数定义变化都会阻止执行。待确认任务只保存在进程内，重启即失效。

MCP 在实际请求前、QQ 发送队列在实际发送前再次检查权限。已经发出的外部请求无法靠本地撤权追回。以后新增含异步等待的敏感工具，需要在副作用前调用 `ctx.assertToolAuthorized()`；服务侧仍应使用最小权限凭据。

命令在外部动作前持久化标记已读，同一 OneBot 消息 ID 的重放不会重复执行。失败或结果不确定时不自动重试。如果进程在标记已读后、实际执行前退出，这次命令可能没有执行，应核对控制台结果后重新发起。

原始聊天和命令保留。会话中记录命令来源、工具、参数哈希、允许/拒绝/完成/错误和确认请求；工具原始结果保存在控制台，电脑状态另向 QQ 返回格式化摘要，其他工具默认只回复执行状态。审计字段不额外存参数明文（原消息与工具调用记录仍可能包含参数）。权限设置仅通过受保护的 `/api/permissions` 修改，通用配置接口拒绝修改该字段。发布脱敏脚本清空管理员、风格、工具规则和命令映射。

这些规则拦截明确的权限、范围、参数、频率和重复执行问题；不承担识别所有自然语言恶意意图的职责。

## 验证

`npm run test:permissions` 使用模拟受限工具、模拟 LLM 与隔离数据目录；`npm run test:mcp` 覆盖 MCP 请求前复查；`npm run test:computer` 验证指标计算、访问控制、格式化回复、发送前撤权和真实本机只读采样。`npm test` 包含全部回归。测试不连接真实 QQ 或付费模型。
