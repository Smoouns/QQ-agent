# 原作者服务与数据上传清理

审查日期：2026-09-12。范围为本仓库维护的 `src/`、`ui/`、`electron/`、安装与开发脚本，以及默认联网配置。通过请求调用点、固定 URL、定时任务、文件读取和调用链检查，并运行隔离测试。

## 已移除

| 入口/机制 | 原行为 | 本次处理 |
| --- | --- | --- |
| 意见收集 | 点击后将昵称、正文和附图上传到作者的 `/qq-agent/api/comment` | 删除按钮、表单、草稿处理及请求代码 |
| 金句上传 | 点击后将勾选的对话及媒体上传到 `/qq-agent/api/holyshits` | 删除按钮、选取状态、确认弹窗及上传代码 |
| 上传取图接口 | `/api/media-data` 通过 OneBot 缓存文件或图片 URL 获取数据，供上传使用 | 整个接口删除；旧路径返回 404 |
| 打开网站、群二维码 | 打开作者网站或展示作者群二维码 | 删除入口、事件处理、样式及二维码文件 |
| 默认用量遥测 | 启动 90 秒后首次上报，之后每 6 小时上报；载荷为持久化安装 ID、版本、LLM 调用次数、Token 用量、工具名称及次数 | 删除遥测模块、启动钩子、定时器、安装 ID 生成与累计计数写入 |
| 作者版本检查 | 前端启动时及每小时请求本地接口，再由后端访问作者的 `version.json`，返回下载链接 | 删除自动/手动检查、后端接口和更新提示；保留读取本地 package.json 的版本显示 |
| 作者宣传页 | 单独的 landing.html 含作者入口、远程主题脚本引用及全站遥测统计请求 | 删除整个宣传页，不再作为本地静态资源提供 |
| 遗留 DSH 导入 | 代码可读取另一个应用的 settings.yaml、相邻 .credentials.yaml 和指定环境变量；当前主流程没有调用入口 | 删除未使用的读取/导入函数与直接 YAML 依赖；保留本项目手动配置的提供商和密钥 |

以上固定作者服务主机为 `kondius.cn`。未将“意见收集”和“金句上传”描述为后台自动上传聊天：原代码需要用户点击；用量遥测则是默认后台执行。没有仅凭功能名称认定作者存在恶意意图。

## 保留的联网与本地数据

- **模型及视觉探测**：按用户选择的提供商调用 API；消息、上下文和工具结果仍会发送给该模型服务。
- **搜索与网页/图片抓取**：按聊天工具请求访问搜索服务、网页和 QQ 媒体地址。
- **MCP**：仅按用户配置的服务、工具启用状态及权限规则执行。
- **OneBot / SnowLuma**：机器人正常收发 QQ 消息所需的协议连接。
- **远程模型价格表**：默认 URL 为空，只有用户配置 URL 才会拉取；代码内置价格表仍可离线使用。
- **本地 Agent 问题反馈**：`report_feedback` 只写当前会话并经本地 SSE 通知控制台，不上传给作者。
- **本地存档与用量页**：聊天、记忆、会话和 usage-today.json 继续保留。旧配置中的 `dshProviderKeys` 是本项目当前手动管理密钥的字段名，保留兼容性，不再读取 DSH 文件。

没有把所有网络能力统一禁用；本次目标是去除原作者的数据收集和推广路径。版权、MIT 许可和兼容现有安装的应用标识不属于联网代码。

## 验证与边界

`npm run test:privacy` 使用独立临时数据目录及模拟 OneBot，执行实际启动和 HTTP 路由，并拦截应用发出的所有 fetch 请求。检查无后台上报定时器、无作者 HTTP 请求、无遥测文件生成、旧接口和静态资源返回 404、本地用量与诊断功能正常。`npm test` 包含该测试及其余回归套件。

此审查不覆盖 SnowLuma 独立发行物、QQ 客户端、用户自己接入的 MCP 服务、模型供应商或 npm 依赖的全部实现，不能据此声称整个运行环境绝无数据采集。已经上传到远端的数据无法通过修改本地代码撤回。

正在运行的旧进程需要重启，才能卸载旧代码及已注册的遥测定时器。旧构建产物也需要重新打包；仅更新源码不会替换已有安装包。
